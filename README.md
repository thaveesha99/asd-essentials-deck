# ASD Essentials — briefing deck

A single-file, web-rendered presentation on the ASD Essentials framework: chapters, domains,
principles, actions and the assessment criteria behind them.

Open `index.html` in a browser, or view it via GitHub Pages.

## Using it

- Arrow keys, Space, Page Up/Down, Home/End to move between slides
- On-screen arrows bottom right, or swipe on touch
- The "framework on one page" slide is interactive: pick a chapter, then a domain or
  principle group, then a principle, then an action to open its assessment criteria
- `Ctrl`/`Cmd` + `P` prints one slide per page

## Source

Content is drawn from the Australian Signals Directorate's **ASD Essentials** series (2026):
the enterprise IT chapter, its asset scoping guide and assessment evidence guide, the cloud
and OT chapters, and the enterprise IT assessment workbook.
